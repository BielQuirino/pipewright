# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| Latest | ✅ |
| Older | ❌ |

We only support the latest published version on npm.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

To report a vulnerability, open a [GitHub Security Advisory](https://github.com/BielQuirino/pipewright/security/advisories/new) on this repository. You will receive a response within 48 hours.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any suggested fix if you have one

We will acknowledge valid reports, work on a fix, and coordinate disclosure with you.
